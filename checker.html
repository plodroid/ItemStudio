Pick the Java version, paste one or more commands, and ItemStudio checks brackets, quotes, command availability, and major version-specific syntax changes.

This is a static vanilla Java syntax linter, not a Minecraft server. It catches known syntax/version mistakes and structural errors; unknown plugin commands are shown as unverified instead of being falsely marked invalid.
